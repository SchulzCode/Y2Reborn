# Reborn Y2 — Simple UI Asset Pack

This is the implementation-oriented asset pack for the simpler Reborn concept.

Included:
- 8 reference screens at the actual 480×360 Y2 resolution
- monochrome 24×24 SVG icon set
- JSON design tokens
- C header tokens
- QSS reference styling
- palette reference
- component sizing guide
- physical navigation model
- Y2-oriented implementation notes
- sample artwork for prototyping

Use the screen images as visual references only. Rebuild the shipping UI using native text, real album art, focusable rows/cards, icons, and live playback metadata.

Core palette:
- background #090B0D
- panel #15191D
- primary text #F2F0EB
- secondary text #A7A9AC
- accent #E7C98B
- focus #FFE2A4

Font files are intentionally not bundled. Inter, Noto Sans, or DejaVu Sans fit this simpler visual direction.
