# Noto (skin fonts)

Noto Sans, Noto Sans Mono, Noto Serif and Noto Serif Display by the Noto Project Authors, SIL Open Font
License 1.1 (`Noto-OFL.txt`), as each font's own licence field says. Source of the licence text:
https://github.com/notofonts/latin-greek-cyrillic, `OFL.txt` at commit
`4bc63d7ebca1faed49c6c685f380ba0abc2c1941`. `tools/assets/build_skins.py` copies it into every skin that
ships Noto fonts as `fonts/Noto-OFL.txt`.
